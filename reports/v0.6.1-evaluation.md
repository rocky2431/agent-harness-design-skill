# 0.6.1 release

Prepared 2026-10-24. Guidance-only release; invariants unchanged.

## Guidance change

- `SKILL.md`: one sentence on durable working state: keep a short current-state view
  apart from append-only history, deliver that view plus a path at recovery within
  host output caps, and protect agent-written records with observers that report and
  keep recoverable copies rather than write gates.
- `references/state-and-orchestration.md`: the two-part working record, the
  observer-instead-of-gate rationale, host hook output caps checked 2026-10-23
  (Claude Code 10,000 characters with a 2,000-character preview; Codex about 2,500
  tokens by default, configurable per handler; Grok 10,000 characters, tool and stop
  hooks only), the pointer-versus-content evidence (Vercel, 2026-01-27, one suite) and
  the navigation-not-instruction lesson from a local resume-loop incident.
- `references/historical-cases.md`: the 2026-10-23 working-record case, what Task
  State 0.7.0 replaced, what was rejected under the owner's principle that mechanical
  enforcement hinders model capability, and the evidence limits.

Evidence classes: the corruption incident and the script-versus-edit count are local
observations from one user's sessions; host caps are documented interface facts on
the checked date; the Vercel figure is a vendor eval used by analogy; the resume-loop
incident is a local report.

## Limits

These are regression smoke checks. Answers are not blind-graded, as in 0.6.0. None of
the 21 selected cases exercises the new working-record rule (the closest, cases 14, 21
and 35, concern capability reduction and history binding), so its effect on answers is
unmeasured. A case asking for the design of an agent-written task record and its
recovery path would test it. The guidance itself was exercised on Task State 0.7.0:
an incident replay, two review rounds, and live Claude Code and Codex checks of
recovery delivery and one post-edit report. Those establish that implementation's
behavior, not this Skill's answer quality.
