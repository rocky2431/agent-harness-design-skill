## Guidance changes (A–C)

- **Upgrade governance:** re-test on upgrade, then retire compensations the new model
  no longer needs. SKILL, adaptation, design decisions and refreshed profiles agree;
  historical cases retain the superseded rule and retirement reason. Existing
  evaluation/observability guidance already supported deletion after measurement.
- **Lighter process:** statement kinds and rule strengths are optional tools for
  disentangling claims. Label evidence where it affects a decision. The recommendation
  core is configuration, proposed change, evidence label and smallest check; other
  fields are conditional. Degradation remains visible to model and recipient; traces
  apply where operators monitor runs. Compatibility guidance specifies truthful
  capability and recovery rather than mandating one typed replacement error.
- **Invariants retained:** externally supplied authority, untrusted data as data,
  trusted credential/effect boundaries, environment-backed success, reachable
  stop/deny/error/recovery, local denials, and no hidden capability reduction.
- **Current profiles:** Anthropic covers Opus/Sonnet/Haiku 5.5 and Fable 5.1; OpenAI
  covers GPT-6.1 Sol and retained dated Astra contracts; xAI adds Grok 4.7 and Grok
  Build. The routing table links all eight provider profiles. Behavioral advice routes
  readers back to current vendor guides; contracts and dated measurements remain
  separate. No runtime or new dependency was introduced.
